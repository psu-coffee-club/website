# Penn State Coffee Club

A single-page site built around the idea of opening a coffee bag and discovering a club evening inside it. The page uses plain HTML, CSS, and JavaScript so it can deploy as a static Vercel site.

## Local preview

Run a static server from this directory, for example:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Site content

- Weekly schedule: Thursdays at HUB-Robeson 102; Brew Team at 6:30 PM, public meeting at 7 PM, official campus block 6:30–8 PM.
- Board names and roles reflect the supplied current officer list.
- Instagram posts are embedded from the public @psucoffee account.
- The coffee bag artwork is original generated art. The header seal and board portraits are temporary treatments pending the club’s approved originals.

## Image files

The PNGs preserve the generated source images. The page uses the smaller WebP versions for faster loading.
